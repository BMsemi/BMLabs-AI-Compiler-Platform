Connect to your workspace

The API uses the same session and project permissions as the dashboard. Get a CSRF token from /api/v1/auth/session/, then include it in the X-CSRFToken header for every write.

Use POST /api/v1/auth/login/ with email and password. Refresh your CSRF token after sign-in. Responses are JSON; list endpoints use pagination.

POST /api/v1/projects/{id}/build/ with {"pipeline":"linear-int8-v1","entrypoint":"model.py"} to queue a supported build (202). Read status, /builds/{id}/stages/, logs and private artifacts. Invalid input returns 400 with a failed build ID; unsupported pipelines return 503. Direct stage execution remains unsupported (501).
