Real Python → IR → RTL verification

Upload a supported literal MODEL input as model.py in a project. Linear builds map to a logical 32×32 PE and compare the repository simulator and RTL with independent vectors. Build records retain commands, logs, mapping, IR, Verilog and actual results. Select Linear synthesis for Yosys, equivalence and netlist checks, or Candidate X2 regression for source-derived Wishbone tests. The FABulous reference pipeline generates and simulates an upstream counter bitstream. Physical fabric, pins, clocks, X2 registers and loader details remain open; they do not block logical simulation. The configured ZCU106 fixed-overlay profile supports a separate read-only board connection check from Project configuration. Programming and numerical hardware execution are not enabled by that check.
